GrabX 1.0.4 — نسخة تجربة لويندوز x64 (Windows 10 / 11)

ابعت لصاحبك ملف GrabX-1.0.4.exe مع هذا الدليل.
المثبت يشمل Java وأدوات FFmpeg/FFprobe وNode وyt-dlp والإضافة.
ما بيحتاج المشروع أو Python أو Java أو تثبيت أدوات منفصلة.
MSI ملف تثبيت بديل؛ استخدم EXE أو MSI، مش الاثنين.

1. شغّل ملف EXE، اختر مكان التثبيت وأكمل المعالج.
2. افتح GrabX من اختصار سطح المكتب أو قائمة Start.
3. اضبط اللغة ومجلد التنزيل وخياراتك من معالج أول تشغيل.
4. ربط المتصفح اختياري. للربط اختار Chrome/Edge/Brave/Chromium.
5. اضغط تجهيز ملفات الإضافة ثم فتح مجلد الإضافة، وافتح صفحة الإضافات في متصفحك.
6. فعّل وضع المطوّر، ثم Load unpacked واختر مجلد chromium الذي جهّزه GrabX.
7. انسخ معرّف الإضافة من المتصفح إلى المعالج واضغط ربط، ثم أعد تحميل الإضافة.
8. عطّل أي نسخة قديمة من الإضافة محمّلة من مجلد آخر قبل تحميل النسخة الجديدة.

الإضافة تُجهّز داخل %LOCALAPPDATA%\GrabX\browser-extension\chromium.
اترك المجلد بمكانه؛ زر نسخ مسار المجلد يساعدك تلاقيه.
Java وأدوات الوسائط المضمّنة خاصة بالتطبيق ولا تغيّر إعدادات النظام.
الإعدادات والتحميلات السابقة محفوظة عند إعادة فتح معالج الإعداد.
لتكرار الإعداد أغلق التطبيق وافتح اختصار GrabX Setup من مجلد التثبيت.

هذه نسخة تجربة شخصية غير موقعة بشهادة ناشر Windows؛ قد يظهر SmartScreen.
راجع مصدر الملف وبصمته في SHA256SUMS.txt، ولا تعطّل حماية النظام.
Firefox وSafari غير مدعومين. نسخة x64 ليست نسخة Windows ARM أصلية.

جديد 1.0.4: تجهيز وفحص الأدوات تلقائيًا حسب النظام والمعالج.
النسخة الكاملة تجهّز الأدوات وتصلح الملفات الناقصة أو التالفة بدون إنترنت.
للإصلاح لاحقًا: الإعدادات ← جهوزية الجهاز ← فحص وتجهيز الأدوات الناقصة.
لربط المتصفح لاحقًا: الإعدادات ← إضافة المتصفح.
إذا الملف سليم لكن النظام يمنع تشغيله، يعرض البرنامج الخطأ؛ راجع نتيجة الحماية.
